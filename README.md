# Tsukerky Vodka

Landing page editorial e inmersiva para Tsukerky Vodka, construida con Next.js,
Tailwind CSS, React Three Fiber y GSAP.

## Desarrollo

```bash
npm run dev
```

## Scripts

- `npm run dev`: inicia el servidor local de Next.js.
- `npm run build`: genera la build de produccion.
- `npm run lint`: ejecuta ESLint.
